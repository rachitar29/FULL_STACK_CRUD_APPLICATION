# Full Stack CRUD Application

**Author: Rachita**

## Overview

A full-stack CRUD application built using Angular, Node.js, Express.js, and MongoDB. The application allows users to create, view, update, delete, and search tutorial records.

## Technologies

* Angular 15
* Node.js
* Express.js
* MongoDB
* Mongoose
* HTML
* CSS
* Git

## Features

* Add tutorials
* View tutorials
* Edit tutorials
* Delete tutorials
* Search tutorials
* MongoDB database integration
* REST API integration
* Responsive user interface

## Setup

### Backend

```bash
cd node-express-server
npm install
node server.js
```

Backend runs on:

```text
http://localhost:8080
```

### Frontend

Open another terminal:

```bash
cd angular-15-client
npm install
ng serve --port 8081
```

Open the application at:

```text
http://localhost:8081
```
